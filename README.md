# VulnScan AI Dashboard (Defensive Demo)

UI-focused website vulnerability scanner concept built with React.

## What this project demonstrates

- Domain input and scan workflow simulation
- OWASP Top 10-aligned finding categories
- Severity scoring and risk posture dashboard
- Claude AI-style remediation summaries and validation checklists
- Exportable markdown security report

## Defensive scope

This project is intentionally defensive. It does **not** include exploit payloads, attack automation, or offensive execution logic. Findings are simulated for triage, remediation planning, and security awareness workflows.

Only assess systems you own or are explicitly authorized to test.
